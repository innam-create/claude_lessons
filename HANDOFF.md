# Hand-off: ZX Spectrum — стан проєкту

**Проєкт:** освітній розділ ZX Spectrum для Software and Computer Museum
(`spectrum.sncmuseum.org`)
**Стан:** **усі розділи MVP-навігації існують**, окрім `/clones/` (заблоковано музеєм,
§7.1). Готово: головна, Історія (таймлайн), Моделі (каталог + компаратор із
«лише відмінності» + картки), Експонати, Софт, Периферія, Контакти, 404, **пошук
Pagefind** (`/search/`). Плюс **SEO/OG**: sitemap із hreflang, robots.txt, Open Graph +
OG-зображення, canonical, **structured data (JSON-LD: Museum · WebSite+SearchAction ·
BreadcrumbList)**. UA+EN скрізь. **Усе злито в `main`** (remote є).
**Оновлено:** 2026-07-21

> Цей документ описує **поточний стан**, а не історію змін. Історія — у `git log`,
> кожен коміт містить розгорнуте пояснення рішень.

## 0. TL;DR — почати за 30 секунд

```bash
npm install
npm run dev      # → http://localhost:4321/   (усі розділи, крім /clones/)
```

Перед комітом:

```bash
npm run check:licenses   # ліцензії зображень (ТЗ §7.2)
npm run check            # типи + розмітка — 0 помилок
npm run build            # 38 сторінок; postbuild сам індексує Pagefind
```

> ⚠️ **Пошук працює лише в зібраному сайті.** Індекс Pagefind будує `postbuild`
> (`pagefind --site dist`), тож у `npm run dev` пошук порожній. Перевіряти через
> `npm run build && npm run preview`. **Деплой мусить робити `npm run build`** —
> інакше `/pagefind/` не згенерується.

Далі читати: **§1** (джерела істини) → **§7** (що робити далі) → **§8** (пастки).

## 4. Дизайн-система

Усі значення — у `src/styles/theme.css`. Використовувати змінні, не хардкодити.

**Колір:** `--bg:#000` · `--text:#D7D7D7` · `--text-dim:#A8A8A8`.
ZX BRIGHT: `--zx-red`, `--zx-magenta`, `--zx-cyan`, `--zx-yellow`, `--zx-white` — можна текстом;
`--zx-blue`, `--zx-green` — **лише заливка/рамка**.
Музей: `--museum-navy/#152A52`, `--museum-gold/#FFD700`.
Маджента — колір компаратора (панель, чипси, таблиця).

**Типографіка:** `--font-pixel` (Retroville, заголовки ≥16px, UPPERCASE) ·
`--font-body` (Golos Text, ≥18px) · `--font-mono` (IBM Plex Mono, метадані).

**Форма:** кути 0; елевація рамками, не тінями; сітка ~1180px. Рух 160–240ms;
поважати `prefers-reduced-motion`. Фокус — видима 2px рамка.

**CRT:** `html.crt`, стан у `localStorage['zx-crt']`, накладка в `BaseLayout`.

## 5. Модель даних

`src/data/models.json` — масив, валідований `src/content.config.ts`:

```jsonc
{
  "id": "zx-spectrum-48k",          // = slug, формує /models/{id}/
  "title": { "uk": "…", "en": "…" },
  "manufacturer": "Sinclair",        // коротка назва → чипс фільтра
  "manufacturerFull": "Sinclair Research",  // повна → рядок «Виробник» у таблиці
  "country": "GB",                   // enum GB|PT|US|PL
  "year": "1982",
  "ram": "48 KB",
  "ramKb": 48,
  "desc": { "uk": "…", "en": "…" },      // короткий — картка каталогу
  "summary": { "uk": "…", "en": "…" },   // розгорнутий — hero картки моделі
  "cpu": "Zilog Z80A", "cpuClockMhz": 3.5, "romKb": 16,
  "video": { "uk": "…", "en": "…" },
  "sound": { "uk": "…", "en": "…" },
  "storage": { "uk": "…", "en": "…" },
  "keyboard": null,                  // null = НЕВІДОМО → «невідомо» курсивом
  "massG": null,
  "sources": [],                     // [] → блок «Джерела ще не додано»
  "images": [                        // [] → «Шукаємо фотографію»; [0] — обкладинка
    {
      "src": "zx-48k.jpg",
      "alt": { "uk": "…", "en": "…" },   // ТЗ §10: описувати, що ВИДНО
      "license": "CC-BY-SA-2.5",         // enum з src/lib/licenses.ts
      "author": "Bill Bertram",
      "source_url": "https://commons.wikimedia.org/wiki/File:ZXSpectrum48k.jpg",
      "accessed": "2026-07-17"
    }
  ],
  "inMuseum": true,
  "confidence": "high"               // low → видимий бейдж «⚠ уточнення» (ТЗ §2)
}
```

**`null` = «невідомо», а не «немає».** Різниця змістовна: у ZX80 звуку **немає**, і це
записано як `{"uk":"Немає","en":"None"}`, а не `null` — інакше таблиця сказала б
«невідомо», що неправда. Не плутати.

**Ліцензійні поля — тверде правило (ТЗ §7.2).** `license`, `author`, `source_url`,
`accessed` обов'язкові. Дві лінії захисту:

1. **Zod** — валить `astro build`, якщо поля бракує.
2. **`npm run check:licenses`** — ловить те, чого схема не бачить: файл відсутній на
   диску, файл-сирота без задокументованої ліцензії, джерело поза ієрархією ТЗ §7.1,
   `accessed` із майбутнього чи неіснуюча дата. Читабельний звіт замість стектрейсу
   Zod. У CI — **перед** збіркою.

**Фільтри виводяться з даних самі** (`buildFilterGroups`): додаси модель — чипси
оновляться. `commercial_use` не пишеться руками — виводиться з `license` (ТЗ §14).

## 6. Astro 5 → 7

Коли вийде Astro 7: `astro@^7`, Node лишається ≥ 22.12. Content Collections,
`file()`-loader та i18n у коді вже в «новому» стилі. Rust-компілятор суворіший до
розмітки — прогнати `npm run build`. Remark/rehype-плагінів немає.

> Через це в коді **немає жодного вкладеного `<a>`** — Astro 7 на цьому впаде (ризик R6).
> Це вплинуло на два рішення: плашка ліцензії в картці каталогу без посилань і
> «розтягнуте посилання» замість обгортки-`<a>` (§8).

### 7.3. Платформа / реліз (ТЗ §3, §9, §10)

**✅ Готово:**
- **Remote є**, увесь код на GitHub (`innam-create/claude_lessons`), злито в `main`
  через 3 PR (#1 контент, #2 SEO/OG, #3 Pagefind). Гілки видалені.

- **Schema.org / JSON-LD** (`src/lib/schema.ts`) — `Museum` site-wide (видавець,

## 8. Пастки (перевірено на власній шкурі)

**CSS Grid: завжди `minmax(0, 1fr)`, ніколи `1fr`.**
`1fr` = `minmax(auto, 1fr)`, а `auto`-мінімум = **min-content** вмісту. Рядок ліцензії
має `white-space:nowrap`, тож його min-content — уся довжина тексту (~338px): колонка
розпирала контейнер **зсередини**, і зміна ширини сітки не допомагала б.

**Піксельний шрифт не переноситься всередині слова.** «ХАРАКТЕРИСТИКИ» на 28px — це
347px у контейнері 288px. Текст малюється **поза** боксом, не розширюючи його: тому
`getBoundingClientRect()` показує норму, а елемент не потрапляє в жоден список
порушників. **Діагностувати тільки через `scrollWidth > clientWidth`.**

**Шапка вимагає ≥ 1280px.** Бургер вмикається на `max-width: 1279px` — це **виміряно**,
а не вгадано: меню з 7 пунктів + інструменти потребують ~1216px контенту. Збігається
з дизайном, де рівно два варіанти: desktop 1280 і mobile 390.
> **Брейкпоінти рахувати по англійській** — вона довша за українську (1246 проти 1185).

**Scoped-CSS Astro не доходить до елементів, створених JS.** Скоуп працює через
data-атрибут, який ставиться лише елементам із шаблону. Таблиця компаратора
рендерилась зовсім без стилів, а `.sr-only` показував службовий текст просто на
сторінці. Рішення — `:global()` під конкретним контейнером (`.cmp-table-wrap`).

**`localStorage` — лише CRT і мова (ТЗ §10).** Вибір моделей у компараторі живе тільки
в пам'яті й скидається при перезавантаженні. Це свідомо, не баг.

**Невідоме — не відмінність.** Компаратор рахує відмінність лише серед **відомих**
значень: «Мембранна · Мембранна · невідомо» — не «≠», бо ми не знаємо, чи значення
інше, і не маємо права це стверджувати. Той самий принцип — скрізь у контенті.

**Pagefind існує лише в білді.** `/pagefind/*` генерує `postbuild`, тож у `dev`
пошук порожній — сторінка чесно каже про це. Імпорт бандла — через
`import(/* @vite-ignore */ '/pagefind/pagefind.js')`, інакше Vite падає на збірці.
Перевіряти пошук — `npm run build && npm run preview`.

**Піксельний заголовок у дві колонки (та сама пастка, новий випадок).** На головній
«ZX SPECTRUM» (~610px, `nbsp`, без переносу) у рівних колонках малювався **поза
боксом** і налазив на фото. Рішення: одна колонка за замовчуванням, дві — лише з
1200px (де копії вистачає місця). Діагноз — знову `scrollWidth > clientWidth`.

**Іконка-пошук у шапці не ламає брейкпоінт §8.** На 1280 (EN, найдовша) шапка з
доданою лупою не переповнюється — виміряно. Додавати ще елементи в `hd-tools`
обережно.

**Мапа Google — клік-для-завантаження (приватність).** Ембед вставляється JS лише
після кліку користувача; авто-`<iframe>` з макета навмисно **не** робив (трекери
на завантаженні). Посилання «Відкрити в Google Maps» працює без ембеда.

**Інше:**
- **Єдиний «мертвий» пункт меню — `/clones/`** (заблоковано §7.1). Решта — живі.
  На головній ще-не-збудовані розділи показуються як «незабаром» (не 404).
- **Хотлінки на Wikimedia не повертати** — усі фото локальні в `src/assets/`.
- **`project/` не збирається** Astro (поза `src/`), виключено в `tsconfig`.
- **Шрифти Google** локально й у проді вантажаться нормально. За бажанням —
  self-host Golos Text / IBM Plex Mono для швидкості й офлайну.
