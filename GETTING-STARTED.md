# ZX Spectrum — spectrum.sncmuseum.org

Освітній розділ ZX Spectrum для Software and Computer Museum. **Astro** з
типізованими Content Collections, i18n (UA/EN) і клієнтськими фільтрами.

Реалізовано розділ **Моделі**. Решта розділів сайту — попереду.

## Як запустити локально

Потрібен **Node.js ≥ 22.12** (версія зафіксована у `.nvmrc`).

```bash
npm install       # встановити залежності (один раз)
npm run dev       # запустити локальний сервер розробки
```

Далі відкрити у браузері:

- http://localhost:4321/models/                  — каталог, українською
- http://localhost:4321/models/zx-spectrum-48k/  — картка моделі
- http://localhost:4321/en/models/               — те саме англійською

## Команди

| Команда | Дія |
|---|---|
| `npm run dev`            | локальний сервер із гарячим перезавантаженням |
| `npm run build`          | статична збірка у теку `dist/` (24 сторінки) |
| `npm run preview`        | переглянути зібраний сайт локально |
| `npm run check`          | перевірка типів і розмітки (astro check) |
| `npm run check:licenses` | перевірка ліцензій зображень (ТЗ §7.2) |

**Перед комітом:** `check:licenses` → `check` → `build`. Те саме робить CI на кожен PR.

  styles/theme.css      токени дизайн-системи (палітра ZX, CRT-режим)

## Що реалізовано

**Каталог `/models/`** — 10 моделей, сітка 1/2/3/4 колонки за брейкпоінтами.
Фільтри (рік · виробник · країна · обсяг ОЗП · наявність у музеї) — клієнтські,
миттєві, комбінуються; лічильник, «скинути», стан «нічого не знайдено».

**Компаратор** — до 3 моделей, вибір кнопкою на картці, таблиця відмінностей.
Невідомі значення не позначаються як відмінність.

**Картка моделі `/models/{slug}/`** — hero, таблиця характеристик, галерея,
блок «В експозиції музею», джерела, навігація попередня/наступна.

**Наскрізне:** дві мови UA/EN, перемикач CRT, бургер-меню, адаптивність 320–1920,
чесні порожні стани («Шукаємо фотографію», «Джерела ще не додано»), плашки ліцензій
із посиланням на текст ліцензії.

## Наступні кроки

Повний стан, рішення й пастки — у **`HANDOFF.md`**. Коротко:

- **Головна** — зараз заглушка; макет `HomePage.dc.html`.
- **`/peripherals/`** (Interface 1, ZX Printer) — не заблоковано, можна робити.
- **`/clones/`** — заблоковано: перелік клонів у ТЗ і в макеті різний, вирішує музей.
- **Верифікація** — характеристики всіх моделей є чернеткою без джерел; за ТЗ §12
  кожна картка має отримати ≥ 2 джерела.
- **Remote і захист `main`** — репозиторію на GitHub ще немає.

> ⚠️ MVP-20 із ТЗ §8.3 **не дописується в `models.json`**: ці 20 позицій
> розкладаються на три розділи сайту (моделі · клони · периферія). У `/models/`
> уже є все, що йому належить. Деталі — `HANDOFF.md` §7.
