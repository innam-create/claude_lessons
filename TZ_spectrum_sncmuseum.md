## 1. Мета та межі проєкту

**Мета.** Освітній ресурс про ZX Spectrum — оригінальні британські моделі Sinclair і українські клони — як тематичне розширення сайту музею для відвідувачів (діти 8+, дорослі без технічної підготовки).

**Не входить у скоуп:** емулятор, користувацький контент, коментарі, форум, збір донатів, синхронізація каталогу з sncmuseum.org, ru-локалізація, власна фотозйомка.

**Ключові показники першої версії (MVP):**
- 20 карток моделей (Sinclair + клони)
- 5 лонгрідів
- дві мови: UA (основна) / EN
- 100 % зображень із задокументованою ліцензією
- Lighthouse ≥ 95 за Performance та Accessibility

## 2. Редакційна політика та контроль якості

**Затвердження.** Жоден матеріал (текст, зображення, картка експоната) не публікується без перевірки та затвердження відповідальною особою музею. Merge до гілки `main` дозволено лише після такого затвердження — воно є обов'язковим кроком у процесі релізу, а не формальністю.

**Генеративний ШІ.** Чернетки текстів (описи моделей, лонгріди, підписи) можуть створюватися за допомогою генеративного ШІ. Згенерований матеріал — це чернетка, а не готова публікація.

**Верифікація фактів.** Усі фактичні твердження — роки випуску, характеристики, ціни, провенанс, атрибуція клонів — підлягають ручній перевірці перед публікацією. Кожне твердження супроводжується посиланням на джерело. Матеріал зі статусом `confidence: low` виходить лише з видимою позначкою «потребує уточнення».

**Технічна фіксація процесу:**
- захист гілки `main`: заборона прямого push, обов'язкове ревʼю щонайменше однієї відповідальної особи в pull request;
- шаблон PR містить чек-лист: факти звірено · джерела вказано · ліцензії зображень заповнено · затверджено;
- CI не замінює людину: він блокує технічні порушення (порожні ліцензійні поля, невалідна розмітка), але не оцінює достовірність — це робить відповідальна особа.

## 3. Домен і хостинг

| Параметр | Значення |
|---|---|
| Субдомен | `spectrum.sncmuseum.org` |
| Тип сайту | статичний (SSG), без бекенду й БД |
| Джерело контенту | Markdown/MDX-файли в Git-репозиторії |
| CMS | відсутня; редагування через Git |
| DNS | CNAME `spectrum` → хостинг-провайдер |
| TLS | автоматичний (Let's Encrypt) |

**Стек:** **Astro 7** (стабільний реліз 22.06.2026, поточна лінія 7.0.x) + MDX + Content Collections + TypeScript.

Причини вибору: нативна i18n-маршрутизація, типізовані колекції контенту зі схемою (валідація полів на етапі збірки), нуль JS за замовчуванням, острівна гідратація лише для фільтрів каталогу.

Обмеження Astro 7, які треба врахувати:

| Пункт | Вимога |
|---|---|
| Node.js | ≥ 22.12 — зафіксувати в `.nvmrc`, у GitHub Actions і в налаштуваннях хостингу |
| Компілятор | Rust (замінив Go), суворіший до розмітки: незакриті теги тепер помилка збірки, а не тихе виправлення |
| Bundler | Vite 8 + Rolldown |
| Markdown | Sätteri (Rust). Кастомні remark/rehype-плагіни або переписуються під Sätteri, або лишається `@astrojs/markdown-remark` |
| Zod | v4, імпорт з `astro/zod`, не з `astro:content` |

Для нашого обсягу (≈40 сторінок × 2 мови) плагіни Markdown навряд знадобляться — беремо дефолтний Sätteri.

**Деплой:** Cloudflare Pages або GitHub Pages + GitHub Actions. Кожен PR → preview-збірка; merge до `main` → продакшн.

## 4. Дизайн-система

### 4.1 Принцип
Спільна каркасна логіка з sncmuseum.org (структура шапки, картковий каталог, футер, типографічна ієрархія) + власна візуальна мова ZX Spectrum.

### 4.2 Палітра
Канонічні 15 кольорів ZX Spectrum (RGB, BRIGHT 0 / BRIGHT 1):

| № | Назва | BRIGHT 0 | BRIGHT 1 |
|---|---|---|---|
| 0 | Black | `#000000` | `#000000` |
| 1 | Blue | `#0000D7` | `#0000FF` |
| 2 | Red | `#D70000` | `#FF0000` |
| 3 | Magenta | `#D700D7` | `#FF00FF` |
| 4 | Green | `#00D700` | `#00FF00` |
| 5 | Cyan | `#00D7D7` | `#00FFFF` |
| 6 | Yellow | `#D7D700` | `#FFFF00` |
| 7 | White | `#D7D7D7` | `#FFFFFF` |

Фон сайту — `#000000`. Основний текст — `#D7D7D7` (не чистий білий: менше різі в очах на чорному).
Райдужна смуга Sinclair (згори вниз: Red → Yellow → Green → Cyan) — акцентний елемент шапки, роздільник секцій, підкреслення активного пункту меню.
Зв'язок із брендом музею: службові елементи (футер, посилання «← до музею») використовують темно-синій `#152A52` і жовтий `#FFD700`.

### 4.3 Типографіка
- Заголовки та UI-акценти: піксельний шрифт ZX-8×8 (WOFF2, лише як декор, обмежені обсяги тексту)
- Основний текст: системний sans-serif stack із повною підтримкою кирилиці; `font-size` ≥ 18px, `line-height` 1.6
- Моноширинний код/лістинги BASIC: `ui-monospace, "Cascadia Code", monospace`

> **Обмеження доступності:** піксельний шрифт заборонено для абзаців, підписів < 16px і будь-яких форм. Контраст усіх пар «текст/фон» — не нижче 4.5:1 (перевірити `#00D700` та `#0000D7` на чорному: синій не проходить, використовувати лише BRIGHT-варіант або як заливку, не як текст).

### 4.4 Компоненти
Шапка з райдужною смугою · перемикач мов UA/EN · картка експоната (фото 4:3, назва, рік, країна, короткий опис) · таблиця характеристик · таймлайн · компаратор моделей · галерея зі скринами (lightbox) · блок «Джерела» наприкінці кожної сторінки · плашка ліцензії під кожним зображенням.

### 4.5 Ретро-фішка
CRT-фільтр (scanlines + легкий glow) — **опційний**, вимикається перемикачем, стан у `localStorage`, за замовчуванням вимкнений; поважає `prefers-reduced-motion`.

## 5. Структура сайту

```
/                       Головна

/models/                Каталог моделей Sinclair (фільтри + компаратор)
```

Дзеркальна структура під `/en/`. Українська — мова за замовчуванням, **без префікса** (`/models/`); англійська — `/en/models/`. `/uk/*` → 301-редирект на `/*`. У Astro: `i18n.defaultLocale: 'uk'`, `routing.prefixDefaultLocale: false`.

### 5.1 Наскрізна навігація
- Шапка: Історія · Моделі · Клони · Експонати · Софт · Периферія · UA/EN
- Хлібні крихти на всіх внутрішніх сторінках
- Футер: логотип музею, адреса (вул. Григорія Сковороди, 79/1), графік (вт–сб, 10:00–18:00), посилання на sncmuseum.org та Instagram

### 5.2 Пошук і фільтри
- Пошук по сайту: **Pagefind** (статичний індекс, будується під час збірки, ~0 KB бекенду)
- Фільтри каталогу (клієнтські, без перезавантаження): рік випуску, виробник, країна, обсяг ОЗП, наявність в експозиції музею
- Компаратор: до 3 моделей одночасно, таблиця відмінностей

## 6. Модель даних

Кожна модель — файл `src/content/models/{slug}.mdx` зі схемою:

```yaml
slug: zx-spectrum-48k
title:
  uk: ZX Spectrum 48K
  en: ZX Spectrum 48K
manufacturer: Sinclair Research
country: GB
year_released: 1982
year_discontinued: 1985
cpu: Zilog Z80A
cpu_clock_mhz: 3.5
ram_kb: 48
rom_kb: 16
video: 256×192, 15 кольорів, attribute clash
sound: 1-bit beeper
storage: компакт-касета
launch_price: { value: 175, currency: GBP }
units_produced: null           # null = невідомо
in_museum: true
inventory_id: SNC-0142         # обов'язкове, якщо in_museum: true
confidence: high               # high | medium | low — потребує верифікації
images:
  - src: ./zx48k-front.jpg
    license: CC-BY-SA-4.0      # enum, див. розділ 14
    author: ...
    source_url: ...
    accessed: 2026-07-08
sources:
  - title: ...
    url: ...
    accessed: 2026-07-08
```

Поле `confidence` обов'язкове. Усе, що `low`, публікується з видимою позначкою «потребує уточнення» — це відповідає практиці каталогізації музею.

`commercial_use` не пишеться руками — виводиться зі значення `license` на етапі збірки.

Аналогічні схеми: `clones`, `peripherals`, `software`, `articles`.

## 7. Зображення: джерела й ліцензії

### 7.1 Ієрархія джерел
**Основа сайту — зображення з офіційних публічних джерел.** Матеріали музею (фото з Instagram) — допоміжні: ілюструють, що саме з описаного можна побачити в експозиції на вул. Григорія Сковороди, 79/1.

| Пріоритет | Джерело | Очікувана ліцензія | Дія |
|---|---|---|---|
| 1 | Wikimedia Commons | CC BY / CC BY-SA / PD | перевіряти ліцензію **на сторінці кожного файлу**, а не на категорії |
| 2 | Internet Archive | різна, часто PD або відкрита | перевіряти поле «Usage rights» кожного айтема |
| 3 | Centre for Computing History (Кембридж) | потребує з'ясування | запит на дозвіл, якщо ліцензія не CC |
| 4 | Science Museum Group Collection | ймовірно CC BY-NC-SA | прийнятно (рішення розд. 14); позначати `commercial_use: false` |
| 5 | Фото музею (Instagram @sncmuseum) | CC BY-SA 4.0 від імені музею | лише в блоках «В експозиції музею» |

World of Spectrum, Spectrum Computing, Speccy.info, ZXPress — **джерела фактів, не зображень**. Їхні скани й скріншоти не мають чистого ліцензійного статусу; використовувати лише як посилання в блоці «Джерела».

### 7.2 Тверде правило
Жодне зображення не потрапляє в репозиторій без заповнених полів `license`, `author`, `source_url`, `accessed`. Перевірка — скриптом у CI: збірка падає, якщо в будь-якому запису `images[]` бракує хоча б одного поля.

### 7.3 Атрибуція
Під кожним зображенням — рядок дрібним кеглем: автор · ліцензія (посилання на текст ліцензії) · джерело. Зведений перелік — на `/sources/`.

### 7.4 Що не використовуємо
- Скріншоти ігор (правовий статус не з'ясовано)
- Скани журналів і мануалів, що не перейшли в PD
- Зображення з піратських архівів і фанатських файлових дампів
- Будь-що з ліцензією ND (заборона похідних) — кадрування під 4:3 є похідним твором

## 8. Контент

### 8.1 Джерела
Первинні: інвентар музею, фотофіксація експонатів, Instagram @sncmuseum (пости-описи експонатів — вичитати й перенести в картки).
Довідкові: World of Spectrum, Spectrum Computing, Speccy.info, ZXPress, Вікіпедія, Ian Adamson & Richard Kennedy «Sinclair and the Sunrise Technology» (1986), журнали «Радіо», «Моделист-конструктор» (схеми клонів), українські архіви й усні свідчення.

Кожен факт — з посиланням. Компільовані з кількох джерел твердження — з позначкою `confidence`.

### 8.2 Роль музейного матеріалу
Контент музею — **допоміжний шар** поверх довідкової основи:
- фото з Instagram @sncmuseum ілюструють блок «В експозиції музею» на картках моделей;
- підписи з постів вичитуються й переносяться в поле опису як локальний контекст (походження конкретного примірника, стан, історія передачі);
- поле `in_museum: true` вмикає на картці плашку «Цей експонат можна побачити в музеї» з графіком роботи.

Технічно: Instagram віддає стиснені JPEG ~1080 px. Достатньо для карток 4:3 і галереї, не достатньо для повноширинних hero-блоків. Hero будувати на графіці (райдужна смуга, піксель-арт, схеми плат), не на фото.

### 8.3 Каталог моделей (20 позицій, чернетка — потребує звірки з інвентарем)

**Sinclair / Amstrad (11):**
ZX80 (1980) · ZX81 (1981) · ZX Spectrum 16K (1982) · ZX Spectrum 48K (1982) · ZX Spectrum 48K+ (1984) · ZX Spectrum 128 «Toastrack» (1986) · ZX Spectrum +2 (1986) · ZX Spectrum +2A/+2B (1987) · ZX Spectrum +3 (1987) · ZX Interface 1 + Microdrive (1983) · ZX Printer (1981)

**Клони та ліцензійні варіанти (9):**
Timex Sinclair 2068 (US, 1983) · Timex Computer 2048 (PL/PT) · «Ленінград-1» (1988) · «Пентагон-128» (1989) · «Байт» (1990) · «Дніпро» · «Компаньйон» · «Спектр-48» · харківські аматорські збірки

> ⚠️ Останні чотири позиції з клонів — **`confidence: low`**. Атрибуцію «українських» клонів слід перевірити фізично й документально: більшість схем 1988–1992 розходилися самвидавом, назви й місця виробництва часто приписуються постфактум. Перед публікацією — звірка з інвентарем і, за можливості, з паспортами/маркуванням плат.

### 8.4 Лонгріди

**MVP (5):**
1. **Від ZX80 до Spectrum: як Клайв Сінклер зробив комп'ютер за £125**
2. **Attribute clash: чому Spectrum виглядає саме так** (відеосистема для нефахівців)
3. **Касета як носій: LOAD "" і звук завантаження**
4. **Спектруми за залізною завісою: клони, схеми, самвидав**
5. **Anatomy of a Speccy: що всередині** (розбір плати 48K по компонентах — спирається на схеми, не потребує польових даних)

**Фаза 2:**
- **Харків 1990-х: спогади власників** — потребує збору інтерв'ю

Кожен лонгрід: 1200–1800 слів UA, EN — переклад. Чернетки готуються ітеративно, фінальна вичитка — на боці музею.

## 10. Нефункціональні вимоги

- **Продуктивність:** LCP < 2.0 с на 3G; зображення — AVIF/WebP з `<picture>`, lazy-loading, розміри в атрибутах
- **Доступність:** WCAG 2.1 AA; повна навігація з клавіатури; змістовний `alt` для всіх зображень (не «фото ZX Spectrum», а опис того, що видно)
- **Адаптивність:** 320–1920 px; каталог — 1/2/3/4 колонки
- **Браузери:** останні 2 версії Chrome, Firefox, Safari, Edge; Safari iOS 16+
- **Без cookie**, окрім `localStorage` для CRT-перемикача й мови
- **Вага сторінки:** < 500 KB

## 14. Ухвалені рішення по спірних пунктах

**Інвентарні дані.** Машиночитної бази немає. Поля `in_museum`, `inventory_id`, `confidence` заповнюються вручну під час звірки з експозицією. Наслідок: у схемі `inventory_id` — необов'язкове поле (`optional`), але за `in_museum: true` CI вимагає його наявності.

**NC-ліцензії.** Зображення з некомерційним обмеженням (CC BY-NC, CC BY-NC-SA) прийнятні — сайт некомерційний. Наслідки, зафіксовані свідомо:
- матеріали сайту не можна ліцензувати єдиною відкритою ліцензією; сторінка `/sources/` містить перелік «змішаних» ліцензій
- у футері не можна ставити загальне «Контент під CC BY-SA» — лише «Текст під CC BY-SA 4.0; зображення — за ліцензіями, вказаними під кожним із них»
- у схемі `images[].license` — enum із дозволеного списку: `PD`, `CC0`, `CC-BY-4.0`, `CC-BY-SA-4.0`, `CC-BY-NC-4.0`, `CC-BY-NC-SA-4.0`, `museum-own`. ND-ліцензії заборонені (кадрування = похідний твір)
- поле `commercial_use: boolean` — виводиться автоматично з `license`, потрібне для фільтра при майбутньому повторному використанні

## 15. Відомий дефіцит

**Зображення клонів.** Радянських і українських Spectrum-сумісних машин на Wikimedia Commons мало, а наявне часто без чіткого ліцензійного статусу. Ймовірний результат: для більшої частини гілки `/clones/` єдиним легальним джерелом фото буде сам музей — тобто саме там допоміжний шар стає основним. Це не блокує запуск, але міняє пропорцію: гілка «Моделі» ілюструється зовнішніми джерелами, гілка «Клони» — власними.

Порядок дій на етапі 3:
1. Спершу проінвентаризувати наявні фото клонів у @sncmuseum
2. Скласти список моделей, які музей має фізично, але не має фото → передати як завдання на зйомку (навіть телефоном) під час найближчої зміни
3. Картки без жодного зображення публікувати з плашкою «Шукаємо фотографію цієї машини» і контактом музею
