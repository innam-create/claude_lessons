# Handoff: ZX Spectrum — тематичний розділ сайту SnC Museum

## Overview
Освітній україномовний розділ сайту Software &amp; Computer Museum (SnC, Харків),
присвячений комп'ютеру **ZX Spectrum** та його екосистемі. Розділ розповідає історію
машини, каталогізує моделі й клони, показує софт, периферію та реальні експонати музею.
Естетика — «ретро ZX» (справжня палітра Spectrum, піксельний заголовковий шрифт,
опційний CRT-режим) поверх сучасної читабельності й доступності (контраст ≥ 4.5:1,
колір ніколи не єдиний носій сенсу).

Мова інтерфейсу — **українська**. У шапці є перемикач UA/EN, але EN-контенту ще немає
(див. «Відомі прогалини»).

## About the Design Files
Файли в цьому пакеті — **дизайн-референси, зроблені в HTML** (Design Components — прототипи,
що показують задуманий вигляд і поведінку). Це **не продакшн-код для прямого копіювання**.
Завдання розробника — **відтворити ці дизайни в цільовому середовищі** з його усталеними
патернами (React/Vue/Astro/статичний генератор/CMS тощо), або, якщо середовища ще немає,
обрати найдоречніший фреймворк і реалізувати дизайни в ньому.

Оскільки контент україномовний і оновлюватиметься музеєм, рекомендовано винести дані
(моделі, статті, клони, софт, експонати) у структуровані джерела (JSON/Markdown/CMS),
а не хардкодити в шаблони. У прототипах дані вшиті в кожен файл лише для наочності.

### Як відкрити прототипи
Кожен `*.dc.html` — самодостатній HTML. Головна точка огляду — **`Макети.dc.html`**:
канва з усіма екранами в парах desktop (1280px) + mobile (390px), включно зі станами
(звичайний / CRT / порожній каталог / 404). `Дизайн-система.dc.html` — повний специмен
токенів і компонентів.

## Fidelity
**High-fidelity (hifi).** Фінальні кольори, типографіка, відступи, стани й взаємодії.
Відтворювати UI піксельно, але засобами цільового кодбейсу. Точні значення — нижче.

## Design tokens

### Колір — базові
- `--bg` `#000000` — тло сайту, чисто чорне
- `--text` `#D7D7D7` — основний текст (навмисно не білий)
- `--text-dim` `#A8A8A8` — підписи, метадані
- Допоміжні відтінки сірого в UI: `#666` (дуже тьмяні підписи/ліцензії), `#2a2a2a` та
  `#333` (рамки карток/розділювачі), `#1c1c1c`/`#151515`/`#0d0d0d`/`#0a0a0a`/`#080808`
  (тло-заливки, штрихування сітки, смуги zebra-таблиць).

### Колір — акценти ZX Spectrum (BRIGHT)
- `--zx-red` `#FF0000` · текст ✓ / заливка / рамка
- `--zx-magenta` `#FF00FF` · текст ✓ (також колір `::selection`)
- `--zx-cyan` `#00FFFF` · текст ✓ — головний «інтерактивний» акцент, метадані, роки
- `--zx-yellow` `#FFFF00` · текст ✓ — колір посилань, головна CTA-заливка
- `--zx-white` `#FFFFFF` · текст ✓ — заголовки
- `--zx-blue` `#0000FF` · **лише заливка/рамка/іконка — НЕ текст на чорному**
- `--zx-green` `#00FF00` · **лише заливка/рамка/іконка — НЕ текст на чорному**
- `--zx-black` `#000000` · тло

### Колір — службові (бренд музею)
- `--museum-navy` `#152A52` — футер, службові блоки, кнопка «до музею»
- `--museum-gold` `#FFD700` — бейдж «В музеї», акцент музею, рамка/текст навігаційної CTA

### Тверді правила доступності
1. Контраст «текст/тло» ≥ **4.5:1**.
2. `#0000FF` (blue) та `#00FF00` (green) **ніколи не текст на чорному** — лише заливка,
   рамка, іконка, плашка.
3. Текст-акцент на чорному дозволено лише: yellow, cyan, white, red.
4. Колір **ніколи не єдиний носій сенсу** — стан завжди дублюється формою, іконкою або
   підписом (напр., «⚠ уточнення» має і жовтий колір, і пунктирну рамку, і підпис).

### Фірмова райдужна смуга Sinclair
Головний підпис бренду: 4 рівні смуги **Red → Yellow → Green → Cyan**
(`#FF0000 / #FFFF00 / #00FF00 / #00FFFF`), зліва направо, гострі краї.
Використання: тонкий роздільник під шапкою (height 6px), підкреслення активного пункту
меню (height 3px, як `linear-gradient(90deg,...)`), декоративний кутовий тег на картці
(height 8px, width 64px), лінія таймлайну. **Ніколи як шпалери/великі площини.**

### Типографіка
- **Заголовки / UI-акценти:** `Retroville` (self-hosted, `fonts/Retroville_NC.ttf`,
  `font-weight: 400 700`), fallback `'Handjet', monospace`. Завжди UPPERCASE, тільки
  великі кеглі та короткі рядки. **Заборонено** в абзацах, підписах &lt;16px та полях форм.
- **Основний текст:** `Golos Text` (Google Fonts, weights 400–800), fallback
  `system-ui, sans-serif`. Body ≥ **18px**, line-height ≥ **1.6**.
- **Моно / роки / специфікації / eyebrow-мітки:** `IBM Plex Mono` (Google Fonts,
  weights 400/500/600). Широкий трекінг для eyebrow: `letter-spacing: .16em–.28em`, uppercase.
- **Код / лістинг BASIC:** `VT323` (Google Fonts), fallback `IBM Plex Mono`. Рендериться
  як ретро-термінал: рамка `1px solid #00FF00`, тло `#020402`, текст `#00FFFF`, номери
  рядків `#FFFF00`, font-size ~22px.

Google Fonts import (у прототипах):
`Golos Text:wght@400;500;600;700;800`, `VT323`, `IBM Plex Mono:wght@400;500;600`,
`Handjet:wght@400;500;600;700`. `Pixelify Sans` завантажується, але **не використовується**
(відбраковано через слабку кирилицю — фінальний піксельний шрифт саме Retroville NC).

### Шкала типу (приблизна)
- Display 64px — `Retroville`, 700, uppercase, line-height ~.9, білий (`ZX SPECTRUM`)
- H2 34px — `Retroville`, 700, uppercase (заголовки секцій; часто жовтий)
- Lead 22px — `Golos Text`, line-height 1.4
- Body 18px — `Golos Text`, line-height 1.6–1.65
- Small 15px — `Golos Text`
- Mono 13–14px — `IBM Plex Mono`, `letter-spacing .04em`, зазвичай cyan для років/метаданих

### Форма, сітка, рух
- **Кути:** radius `0` за замовчуванням. Дозволено один фірмовий «зрізаний кут» на картці
  (`clip-path: polygon(0 0, 100% 0, 100% 72%, 72% 100%, 0 100%)`). Без пілюль.
- **Елевація — рамками, не тінями:** рамки 2px (`#2a2a2a` спокій → `#00FFFF` hover на
  картках). Тіні лише для справжніх оверлеїв (меню/модалки), стримані й холодні.
- **Сітка:** 12 колонок, макс. ширина контенту ~**1200px** (у макетах фрейми 1280px),
  лонгріди — вузька колонка ~**720px** (фрейм 900px). Крок сітки 8px.
- **Breakpoints (з макетів):** desktop ~1280px, mobile 390px. Компоненти приймають проп
  `variant: 'desktop' | 'mobile'` — на реальному сайті це звичайний responsive-брейкпоінт.
- **Рух:** 160–240ms, `ease-out`. Без bounce, без важкого parallax. Сигнатурна анімація —
  сітка «заповнюється» плитками. Поважати `prefers-reduced-motion`.
- **Hover:** посилання → зсув кольору жовтий↔cyan + підкреслення; рамки → ріст контрасту
  (часто до `#00FFFF` або `#FFFF00`); жовта CTA → темніє до `#FFD700`.
- **Focus:** видима 2px рамка (blue), не прибирати.

## Screens / Views
Повний перелік і розміри фреймів — у `Макети.dc.html`. Сторінки:

1. **HomePage** (`HomePage.dc.html`) — головна. Герой із реальним фото 48K, 7 категорійних
   плиток (Історія, Моделі, Клони, Експонати, Софт, Периферія, Контакти). Проп `crt`
   вмикає CRT-накладку (scanlines + glow).
2. **CatalogPage** (`CatalogPage.dc.html`) — каталог моделей. Ліва панель фільтрів
   (рік / виробник / країна / ОЗП / наявність у музеї) — фільтри toggle-ються, фільтрують
   і комбінуються. 8 моделей; проп `empty="true"` показує стан «нічого не знайдено».
   Картки з реальним фото / чесним «⚠ уточнення» / «Шукаємо фотографію».
3. **ModelDetailPage** (`ModelDetailPage.dc.html`) — найважливіший шаблон. Хлібні крихти
   «Моделі», навігація prev/next, таблиця характеристик (null → «невідомо», курсив,
   не порожньо), галерея 4:3, блок джерел. Проп `model` вибирає одну з 8 моделей;
   обгортки `Model-*.dc.html` фіксують кожну.
4. **HistoryHubPage** (`HistoryHubPage.dc.html`) — хаб «Історія»: таймлайн 1980–1992 +
   3 статті (48КБ, касета, ZX81), кожна веде у свій лонгрід.
5. **LongreadPage** (`LongreadPage.dc.html`) — шаблон лонгріду, вузька колонка ~720px:
   заголовок, тіло, ілюстрація з підписом-атрибуцією, цитата, лістинг BASIC, джерела.
   Обгортки `Лонгрід-48k / Лонгрід-касета / Лонгрід-zx81` задають контент кожної теми.
6. **ClonesPage** (`ClonesPage.dc.html`) — клони (Didaktik M/Gama, Дубна 48К, Ленінград-1,
   Дельта-С). Картки без фото + чесний заклик надіслати фото на info@sncmuseum.org.
7. **SoftwarePage** (`SoftwarePage.dc.html`) — софт та ігри. Обкладинки-плейсхолдери,
   **без** кнопок «Запустити/емулятор» (свідоме рішення).
8. **PeripheralsPage** (`PeripheralsPage.dc.html`) — периферія, патерн каталогу.
9. **ExhibitsPage** (`ExhibitsPage.dc.html`) — реальні експонати музею; бейдж «★ В музеї»
   (gold) + заклик прийти. Використовує `ExhibitCard.dc.html`.
10. **ContactsPage** (`ContactsPage.dc.html`) — адреса (Гігант ХПІ), Google Maps iframe,
    Instagram/Facebook @sncmuseum, безкоштовний вхід.
11. **NotFoundPage** (`NotFoundPage.dc.html`) — 404 у стилі «R Tape loading error».

- **CTA «до музею»:** `IBM Plex Mono` 14px, `background:#152A52`, `color:#FFD700`,

  сіткою (`linear-gradient` 18px). Плашка ліцензії — `IBM Plex Mono` 11px `#666` над
  контентом. Кутовий райдужний тег 8px×64px.
- **Картка без фото:** по центру великий `?` кольору `#FF00FF`, підпис «Шукаємо
  фотографію цієї машини», контакт `info@sncmuseum.org` (cyan).
- **Таблиця характеристик:** zebra-рядки `#080808`/`#0c0c0c`, ключ `IBM Plex Mono` 13px

  `@keyframes zxflicker` (opacity .96↔1, 4s). За замовчуванням **вимкнено**, перемикач у
  шапці. Мусить поважати `prefers-reduced-motion`.

## Interactions &amp; Behavior
- **Навігація:** усі внутрішні лінки в прототипах ведуть на `*.dc.html`; у продакшні —
  замінити на маршрути застосунку. Зовнішні (джерела/соцмережі/sncmuseum.org) — реальні URL.
- **Фільтри каталогу:** кожен чіп — toggle; активні фільтри комбінуються (AND між групами).
  Порожній результат → стан «нічого не знайдено».
- **CRT toggle:** глобальний перемикач стану; накладка рендериться поверх усього контенту.
- **prev/next** на сторінці моделі йде по фіксованому порядку:
  `16k → 48k → plus → 128 → plus2 → plus3 → timex → plus2a`.

## State Management
- `crt: boolean` — глобальний (перемикач у шапці). Рекомендується персистити в
  localStorage.
- `activeNav: string` — поточний пункт меню (виводиться з маршруту).
- Каталог: `filters: { year[], maker[], country[], ram[], inMuseum }` → похідний
  відфільтрований список + `empty` стан.
- Локаль `UA | EN` — перемикач присутній, EN-контенту немає (див. прогалини).
- Дані сторінок (моделі/статті/клони/софт/експонати) — винести у контент-джерело.

## Design system
Розділ побудований на **SnC Museum Design System** (бренд музею: navy `#152A52`, gold
`#FFD700`, прапорні акценти, квадратно-сіткова графіка, гострі кути, рамки замість тіней,
Montserrat/PT Sans/IBM Plex Mono). Ретро-шар ZX (чорне тло, палітра Spectrum, Retroville,
CRT) — тематична надбудова саме цього розділу поверх музейного бренду; музейний бренд
лишається у службових зонах (футер, кнопка «до музею», бейдж «В музеї»). У продакшні
використовувати наявну реалізацію дизайн-системи музею, а ретро-токени додати як тему розділу.

## Відомі прогалини / рішення для замовника
1. **EN-локалізація:** перемикач UA/EN є, англійського контенту немає. Вирішити: будувати
   EN одразу чи прибрати перемикач до готовності перекладу.
2. **Фото музею:** замінити плейсхолдери реальними знімками (див. список вище).
3. **Контент-модель:** винести дані у структуроване джерело (CMS/JSON), бо контент
   оновлюватиме музей.
4. **Софт:** свідомо без емуляторів/кнопок «Запустити» — підтвердити на майбутнє.
5. **Стек:** цільове середовище не задане — обрати фреймворк або підтвердити інтеграцію
   в наявний сайт sncmuseum.org.
