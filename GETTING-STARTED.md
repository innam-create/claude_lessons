# ZX Spectrum — каталог моделей (spectrum.sncmuseum.org)

Реалізація сторінки **Каталог моделей** (`/models/`) для освітнього розділу
ZX Spectrum сайту Software and Computer Museum. Побудовано на **Astro** з
типізованими Content Collections, i18n (UA/EN) та клієнтськими фільтрами.

## Як запустити локально

Потрібен **Node.js ≥ 22.12** (версія зафіксована у `.nvmrc`).

```bash
npm install       # встановити залежності (один раз)
npm run dev       # запустити локальний сервер розробки
```

Далі відкрити у браузері:

- http://localhost:4321/models/    — каталог, українською
- http://localhost:4321/en/models/ — каталог, англійською

## Команди

| Команда | Дія |
|---|---|
| `npm run dev`     | локальний сервер із гарячим перезавантаженням |
| `npm run build`   | статична збірка у теку `dist/` |
| `npm run preview` | переглянути зібраний сайт локально |
| `npm run check`   | перевірка типів (astro check) |

## Структура

```
src/
  content.config.ts     схема моделей (Zod) — валідація на етапі збірки
  data/models.json      дані 8 моделей (UA/EN) — редагується музеєм
  i18n/ui.ts            рядки інтерфейсу UA/EN + маршрутизація мов
  lib/                  нормалізація моделей, групи фільтрів, мапа зображень
  styles/theme.css      токени дизайн-системи (палітра ZX, CRT-режим)
  components/           Header, Footer, ModelCard, CatalogView, RainbowBar
  layouts/BaseLayout.astro
  pages/
    models/index.astro     каталог (UA, без префікса)
    en/models/index.astro  каталог (EN, /en/)
    index.astro            мінімальна головна
src/assets/models/      фото моделей (оптимізуються в WebP/AVIF автоматично)
public/fonts/           Retroville_NC.ttf (піксельний заголовковий шрифт)
```

## Що реалізовано

- Каталог 8 моделей: сітка карток 1/2/3/4 колонки за брейкпоінтами
- Фільтри (рік · виробник · країна · обсяг ОЗП · наявність у музеї) —
  клієнтські, миттєві, комбінуються; лічильник; «скинути»; стан «нічого не знайдено»
- Панель компаратора (до 3 моделей), картки без фото з плашкою
  «Шукаємо фотографію», бейджі «В музеї» / «⚠ уточнення», плашки ліцензій
- Дві мови UA/EN, перемикач CRT (стан у localStorage), мобільне бургер-меню

## Наступні кроки

- Сторінки інших розділів (Історія, Клони, Софт, Периферія, Експонати,
  Контакти, картка моделі) — у меню вже є посилання на їхні майбутні адреси.
- Розширити `models.json` до повного MVP-переліку (ZX80/81, клони тощо) —
  схема це вже підтримує.
